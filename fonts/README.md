# The Abrahamic Library — the typefaces

The fonts [The Abrahamic Library](https://abrahamiclibrary.com/) is set in.

## Gentium Plus and Gentium Book Plus

Both families are by SIL International, designed for legibility across
scripts and used here for the Scripture text and the headings of the
printed companion volume (`../bible/`). The site itself uses a
system-font stack, so these files serve the print pipeline and any future
typography rather than the web pages.

| File | Weight |
|------|--------|
| `GentiumPlus-Regular.ttf` | Roman |
| `GentiumPlus-Italic.ttf` | Italic |
| `GentiumPlus-Bold.ttf` | Bold |
| `GentiumPlus-BoldItalic.ttf` | Bold italic |
| `GentiumBookPlus-Regular.ttf` | Roman, heavier for smaller text |
| `GentiumBookPlus-Italic.ttf` | Italic |
| `GentiumBookPlus-Bold.ttf` | Bold |
| `GentiumBookPlus-BoldItalic.ttf` | Bold italic |
